'Netdriver' is the name of a high-level cyberdeck from Cyberpunk 2077. The only other cyberdeck at this tier, is <a href="/canto/">Canto</a>.

# Previous work

Having made the switch from Windows to NixOS last year, I've been enjoying using the terminal for day-to-day computing and would like to create a terminal-only system to explore its usability.

My previous setup combined kitty and fish with little to no further customisation. This new device will likely force me to engage with the terminal/shell environment more than I have done previously.

# Design

Instead of running a graphical display, the idea is to instead 100% rely on the default Linux Virtual Terminal (the screen you're greeted with when accessing a headless Linux system).
